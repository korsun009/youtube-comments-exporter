# Экспорт комментариев YouTube v6

Независимый проект, выделенный из [исходного набора](https://github.com/korsun009/youtube-export-bookmarklets), commit c2dce844bbcf60d2699930e501127f07e6b889fb. Старые версии сохранены в исходном репозитории.

## Установка

Откройте [bookmarklet](youtube-comments-api-exporter-v6/youtube-comments-api-bookmarklet-v6.txt), скопируйте полное содержимое в URL новой закладки браузера. Откройте видео YouTube и нажмите закладку. Для DevTools Snippet используйте [исходник](youtube-comments-api-exporter-v6/youtube-comments-api-exporter-v6.js). Полная инструкция и ограничения: [руководство](youtube-comments-api-exporter-v6/youtube-comments-api-exporter-v6-readme.txt).

## Состояние закладки на 28.10.2026

Установленная закладка Vivaldi содержит вложенный `javascript:`, два тела скрипта и не проходит синтаксическую проверку после декодирования (Unexpected identifier strict). Она содержит полный канонический v6. Для установки используйте рабочий файл выше. Повреждённый оригинал сохранён отдельно в локальном архиве; в репозиторий включена рабочая сборка. Закладки браузера не менялись.

## Проверки

Нужен Node.js 20 или новее, внешних зависимостей нет. Запустите `npm run verify` для тестов и воспроизводимой сборки. Тесты проверяют обработку данных и ошибки на синтетических примерах; реальный экспорт в браузере при выделении проекта не запускался.

В репозитории только код, документация и тесты. Ключи API и экспортированные пользовательские данные не включены.
